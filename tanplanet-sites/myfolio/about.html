เกี่ยวกับผม

ผม ณัฐปคัลภ์ ศิริรัตน์ (แทน) เป็น Product Designer จากประเทศไทย และสนใจการนำเครื่องมือ AI มาประยุกต์ใช้ในการทำงานออกแบบ ผมเริ่มต้นทุกโปรเจกต์ด้วยการตั้งคำถามที่มีความหมาย เพื่อทำความเข้าใจปัญหาอย่างลึกซึ้ง และออกแบบโซลูชันที่เรียบง่าย รอบคอบ และมีผู้ใช้งานเป็นศูนย์กลาง
‍
ด้วยความอยากรู้อยากเห็นโดยธรรมชาติ ผมนำแนวคิดจากหลายสาขา เช่น ปรัชญา วิทยาศาสตร์ การเมือง และวัฒนธรรม มาช่วยขยายมุมมองในการออกแบบ เพราะผมเชื่อว่าผลิตภัณฑ์ที่ดีเริ่มต้นจากการเข้าใจผู้คน ไม่ใช่เพียงแค่หน้าจอ
ในเวลาว่าง ผมชอบการเดินทาง การถ่ายภาพ และการใช้เวลากับสุนัข พร้อมค้นหาแรงบันดาลใจใหม่ ๆ จากโลกที่อยู่รอบตัว

แบรนด์

tanplanet — บันทึกของแทน

tanplanet คือไดอารี่ที่ผมใช้เก็บประสบการณ์และความทรงจำ แล้วแชร์ต่อให้คนอื่น เพื่อทบทวนตัวเองและเติบโตขึ้นทุกวัน

  • พระอาทิตย์ทุกวันคือหน้าใหม่ เริ่มด้วยการทบทวนว่าเมื่อวานได้เรียนรู้อะไร
  • ภูเขาประสบการณ์ที่ค่อย ๆ สะสม จนกลายเป็นฐานที่มั่นคงของงาน
  • สายน้ำความทรงจำที่ไหลต่อ ส่งต่อให้คนอื่นได้ใช้และต่อยอด

ทักษะของผม

ออกแบบ UX/UI

ออกแบบโปรดักต์ SaaS ครบกระบวนการ ตั้งแต่ user flow และ wireframe ไปจนถึง prototype แบบ high-fidelity ทั้งเว็บและแอป

Design System

วาง token, component และแนวทางการใช้งานกลาง ให้ทั้งทีมออกแบบและพัฒนาไปในทางเดียวกัน

UX Research

สัมภาษณ์ผู้ใช้ ทดสอบ usability และอ่านข้อมูลการใช้งาน เพื่อหาปัญหาที่ควรแก้ก่อน

สร้างโปรดักต์ด้วย AI

ใช้ AI อย่าง Claude Code สร้างต้นแบบและเครื่องมือที่ใช้งานได้จริง ตั้งแต่ไอเดียจนขึ้นออนไลน์

Frontend

เขียน HTML, CSS และ JavaScript ได้ ส่งต่องานให้ dev ตรงกับดีไซน์ และแก้หน้าเว็บเองได้

UX Writing

เขียนข้อความในหน้าจอ ปุ่ม และ error ให้สั้น เข้าใจง่าย รวมถึงบทความและคอนเทนต์

คำถามที่พบบ่อย

แทน (ณัฐปคัลภ์ ศิริรัตน์) คือใคร

แทน หรือ ณัฐปคัลภ์ ศิริรัตน์ (Natpakan Sirirat) เป็น Product Designer และ AI Builder จากประเทศไทย ออกแบบ UX/UI ของโปรดักต์ดิจิทัลมาตั้งแต่ปี 2021 และใช้เครื่องมือ AI สร้างเครื่องมือที่ใช้งานจริงด้วยตัวเอง

ตอนนี้แทนทำงานที่ไหน

ตั้งแต่ปี 2025 แทนเป็น UX/UI Designer ที่ Real Factory บริษัท SaaS ที่เปลี่ยนข้อมูลซับซ้อนให้เป็นข้อมูลเชิงลึกสำหรับธุรกิจในประเทศไทย ดูแลตั้งแต่ user research จนถึง prototype และ design system

แทนเคยทำงานที่ไหนมาบ้าง

แทนถนัดงานแบบไหน
