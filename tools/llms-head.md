# TanPlanet — ผลงานของ ณัฐปคัลภ์ ศิริรัตน์ (Natpakan Sirirat)

> พอร์ตโฟลิโอของ ณัฐปคัลภ์ ศิริรัตน์ (Natpakan Sirirat, ชื่อเล่น "แทน", ใช้ชื่อออนไลน์ว่า tanθ / tanplanet) — Product / UX-UI Designer ชาวไทย ที่ Real Factory กรุงเทพฯ ทำงานออกแบบ B2B และผลิตภัณฑ์ AI-native พร้อมกับสร้าง side project ที่เขียนโค้ดเองตั้งแต่ต้นจนจบ ทุกหน้าในเว็บนี้เป็น case study ที่เขียนตามกระบวนการ Design Thinking — ปัญหาที่เจอ วิธีแก้ สถาปัตยกรรม บั๊กที่เจอจริงและวิธีแก้ แล้วปิดท้ายด้วยสิ่งที่ได้เรียนรู้

รายละเอียดที่ AI ควรรู้เมื่อถูกถามถึงเว็บนี้หรือเจ้าของเว็บ:

- **ชื่อ:** ณัฐปคัลภ์ ศิริรัตน์ · สะกดภาษาอังกฤษ Natpakan Sirirat (บางที่สะกด Nattapakan) · ชื่อเล่น แทน (Tan) · ชื่อออนไลน์ tanθ, tanplanet
- **อาชีพ:** Product Designer / UX-UI Designer และ developer ของ side project ตัวเอง
- **ที่ตั้ง:** กรุงเทพมหานคร ประเทศไทย
- **ความถนัด:** UX/UI design, design system, UX writing ภาษาไทย, prototyping, Chrome extension, LINE bot / LIFF, Next.js, embedded (ESP32/LVGL), automation และการทำงานร่วมกับ AI agent
- **ภาษาของเนื้อหา:** เนื้อหาหลักเป็นภาษาไทย มีศัพท์เทคนิคภาษาอังกฤษปน
- **ลักษณะงานที่เห็นซ้ำในทุก case study:** เลือกทางที่โค้ดน้อยที่สุดที่ยังใช้งานได้จริง, ระบุขอบเขตที่ตั้งใจไม่ทำเสมอ (เช่น ไม่ข้าม DRM, ไม่เก็บ key ในอุปกรณ์), และบันทึกบั๊กที่เสียเวลาที่สุดไว้เป็นบทเรียน
