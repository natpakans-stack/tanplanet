ภาพรวม

หลังจากทีม BKK ร่วมกับทีม Lukkid เก็บ requirement จากทั้งหมอและผู้ป่วย ผมได้ออกแบบ UX และ UI เพื่อแก้ปัญหาที่ผู้ป่วยเจอ ตาม requirement ที่เก็บมา พอพัฒนา Prototype (MVP1) เสร็จ ผมจัดเซสชันให้ผู้ป่วย 10 คนได้ลองใช้และให้ feedback แล้วเราเอาไปปรับปรุงเวอร์ชันถัดไป

โปรเจกต์นี้เป็นความร่วมมือกับโรงพยาบาล Siriraj และ Huawei เพื่อพัฒนาแพลตฟอร์มอัจฉริยะที่ยกระดับบริการทางการแพทย์ด้วยเทคโนโลยีใหม่ๆ เป้าหมายคือพัฒนาคุณภาพบริการสาธารณสุขของไทยในภาพรวม ทุกโปรเจกต์จัดแสดงภายใต้โครงการ “Siriraj 5G” ซึ่งโปรเจกต์ของทีม BKK ของเราก็เป็นหนึ่งในนั้น งานนี้มีนายกรัฐมนตรีเป็นประธาน

‍

ผู้เกี่ยวข้องหลัก

‍

1. ผู้ป่วย (ที่เป็นโรค NCDs)

Empathize: ผู้ป่วยมักดูแลสุขภาพได้ไม่สม่ำเสมอ และจำตารางกินยาที่ซับซ้อนได้ยาก
Define: ผู้ป่วยต้องการการแจ้งเตือนที่ตรงเวลา และวิธีบันทึกข้อมูลสุขภาพประจำวันที่ง่าย
Solution: ระบบแจ้งเตือนกินยาแบบเฉพาะคนตามที่หมอสั่ง และให้ผู้ป่วยบันทึกค่าสุขภาพสำคัญได้เอง เช่น BMI น้ำตาลในเลือด ความดัน การออกกำลังกาย และอาหาร ทำให้ผู้ป่วยรู้จักสุขภาพตัวเองมากขึ้น และดูแลสุขภาพตัวเองได้

2. บุคลากรสาธารณสุข

Empathize: บุคลากรสาธารณสุขอยากให้คำแนะนำที่ตรงจุดและได้ผล แต่มักไม่เห็นข้อมูลพฤติกรรมประจำวันของผู้ป่วยแบบ real-time
Define: ต้องมีเครื่องมือที่ช่วยให้เข้าไปดูแลได้ทันเวลา และปรับแผนการดูแลได้ตามสถานการณ์
Solution: ระบบให้บุคลากรสาธารณสุขแนะนำแบบเฉพาะคน และปรับแผนการรักษาได้ตามผลที่ผู้ป่วยรายงานเข้ามา ทำให้การดูแลตรงจุดและตอบสนองได้เร็วขึ้น

3. หมอ

Empathize: หมอมีเวลาจำกัด และเข้าถึงข้อมูลผู้ป่วยแบบรอบด้านได้น้อยระหว่างตรวจ
Define: หมอต้องการเข้าถึงข้อมูลสุขภาพที่ถูกต้องและต่อเนื่องได้อย่างรวดเร็ว เพื่อใช้ตัดสินใจ
Solution: แพลตฟอร์มแสดงภาพรวมของผู้ป่วยที่ครบและเป็นปัจจุบัน หมอจึงเข้าใจอาการได้เร็วขึ้น และแนะนำการรักษาที่แม่นยำและเฉพาะคนมากขึ้น รองรับทั้งการตรวจที่โรงพยาบาลและการดูแลทางไกล (Telemedicine)

User Journey

ช่วง COVID-19 ทีมเราส่งต่อผู้ป่วยไปที่ศูนย์เบาหวาน โรงพยาบาล Siriraj เพื่อติดตามอาการอย่างใกล้ชิด ให้แผนการรักษาเดินต่อได้ แต่เพราะมาตรการกักตัวทำให้ผู้ป่วยเดินทางไปพบหมอและนักโภชนาการไม่ได้ เราจึงออกแบบ flow การดูแลทางไกลที่ใช้เทคโนโลยีช่วยให้รักษาและติดตามอาการได้ต่อเนื่อง

Dashboard ของหมอ

นอกจากแอปฝั่งผู้ป่วยแล้ว เราอยากให้ผู้ใช้บันทึกเรื่องต่างๆ ในชีวิตประจำวันได้ เช่น มื้ออาหาร การกินยา น้ำหนัก อารมณ์ ความดัน และระดับน้ำตาลในเลือด ข้อมูลเหล่านี้หมอก็เข้าดูได้ด้วย ทำให้วินิจฉัยได้แม่นขึ้นและปรับยาได้ละเอียดขึ้น ช่วยลดเวลาซักประวัติ และแก้ปัญหาที่ผู้ป่วยลืมหรือเล่าพฤติกรรมไม่ละเอียดตอนมาพบหมอ เช่น แต่ละมื้อกินอะไรไปบ้าง พอข้อมูลถูกบันทึกผ่านแอป หมอก็ดูพฤติกรรมผู้ป่วยได้ทันที ซึ่งยังรองรับ telemedicine ในอนาคตด้วย
