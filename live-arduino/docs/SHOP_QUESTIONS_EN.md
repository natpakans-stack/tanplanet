# Shop Questions

Send this to the seller before buying the 3.5" board.

```text
Hi, I want to buy the 3.5 inch ESP32 LVGL display with case.

Can you confirm the exact model number?
Is it ESP32-3248S035R or ESP32-3248S035C?

What is the screen resolution?
Is it 320x480?

What display driver does it use?
For example ST7796, ILI9488, or another driver.

What touch type and touch driver does it use?
Is it resistive touch with XPT2046, or capacitive touch with GT911?

Does the board have an audio amplifier or speaker output?
Is there a SPEAK / P4 speaker connector on the board?

Is a speaker included in the package?
If not, what speaker specification should I buy?
For example 8 ohm speaker.

Do you provide example code, pinout, or Arduino/LVGL library configuration for this exact 3.5 inch model?

Does the case fit this exact 3.5 inch board model?
Will it block the USB port, BOOT/RESET buttons, SD card slot, or speaker connector?

Is the USB port Type-C or Micro-USB?

Does it work with Arduino IDE on macOS?
```
