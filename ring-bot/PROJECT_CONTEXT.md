## หลักการสำคัญ

ระบบห้ามส่ง LINE ลัดหลังบ้าน งานอัตโนมัติต้องสร้าง record ในแท็บ `bills` ก่อนเสมอ
จากนั้นให้ `ringTick` pipeline เดิมส่งข้อความ อัปเดตสถานะ และเขียน `pushlog`

ข้อมูลคงที่อ่านจากแผงควบคุม:

- PromptPay แม่: บิลล่าสุดที่ `คู่กรณี=แม่` และ `ธนาคาร` ขึ้นต้นด้วย `พร้อมเพย์`
- PromptPay แทน: บิลล่าสุดที่ `คู่กรณี=แทน` และ `ธนาคาร` ขึ้นต้นด้วย `พร้อมเพย์`
- LINE ของโจ้: `ปลายทาง` ของบิลแม่หรือแทนล่าสุด และต้องมีอยู่ใน `targets` ชนิด `user`
- Script Properties `BUDGET_MOTHER_PROMPTPAY`, `BUDGET_TAN_PROMPTPAY`,
  `BUDGET_LINE_USER_ID` เป็น optional overrides เท่านั้น
- `BUDGET_SEND_DAY` และ `BUDGET_SEND_TIME` เป็น optional overrides; defaults คือวันที่ 28 เวลา 09:00

## MEA Safety Gate

ก่อนสร้างบิล ระบบต้องตรวจ:

1. พบ label `ค่าไฟ***`
2. ช่องขวามีสูตรรูปแบบ `=number*0.6`
3. ยอดค่าไฟมากกว่าศูนย์
4. Note มีข้อความ `อัปเดตอัตโนมัติจาก MEA e-Invoice`
5. Note มี `รอบบิล` เป็นเดือนก่อนหน้าแท็บเป้าหมาย
6. พบยอดแม่และแทนครบและมากกว่าศูนย์

ถ้ายังไม่พร้อม ระบบไม่สร้าง record/QR/LINE และลองใหม่ใน `ringTick` รอบถัดไป

Apps Script ฝั่ง Budget-Bajjo ไม่ได้ถูกแก้ในงานชุดนี้ Property เช่น
`MEA_INVOICE_25595251753` อยู่ฝั่ง Budget-Bajjo และใช้ป้องกันประมวลผลใบแจ้งซ้ำ

## Logs ใน Google Sheet หลัก

- `bills`: records ของบิลแม่และแทนก่อนส่ง
- `pushlog`: ผลการเรียก LINE
- `budgetlog`: เวลา, เดือน, แท็บ Budget-Bajjo, สถานะ, รายการ, รายละเอียด
- สถานะ budget log: `ยังไม่สร้างบิล`, `สร้างบิลแล้ว`, `ส่งสำเร็จ`, `ส่งไม่สำเร็จ`
- error ข้อความเดิมบันทึกครั้งเดียวจนกว่าสาเหตุจะเปลี่ยน
- `ringSetup` สร้างแท็บ `budgetlog`; หากไม่รัน แท็บจะถูกสร้างเมื่อมี log ครั้งแรก
