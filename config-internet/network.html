  • เน็ตวิ่งวนเป็นลูป ระหว่าง Huawei กับ Deco หน้า Kitchen ในแอปขึ้นว่า "Connected to: Bedroom" (ไร้สาย) และเห็น Huawei ชั้น 1 (HG8045X6-12) เป็นแค่เครื่องลูกที่ต่อสายเข้ามา แปลว่ามีทางวิ่งระหว่างชั้น 3 กับชั้น 1 อยู่ 2 ทางพร้อมกัน ทางแรกผ่าน Huawei mesh ทางที่สองผ่าน Deco mesh ทั้งสองทางต่อถึงกันด้วยสายที่ปลายทั้งสองข้าง ข้อมูลอาจวิ่งวน หรือสลับทางไปมา อาการที่เห็นคือ ping กระโดดและเน็ตหลุดเป็นช่วง ๆ หลักฐาน: แอป Deco หน้า Kitchen · 26 ต.ค. 2026 11:21 · แยก Deco เป็นวงเดี่ยวแล้วลูปนี้จะหายไป
  • ชั้นล่างได้เน็ตผ่าน Wi-Fi ที่ทะลุพื้นคอนกรีต ชั้น 2 กับชั้น 1 ไม่มีสายจาก ONT ลงมา Huawei mesh ต้องรับสัญญาณไร้สายจากชั้นบน แล้วปล่อยต่อให้ Deco ทุกทอดที่ส่งไร้สายจะเสียความเร็วไปราวครึ่งหนึ่ง พื้นคอนกรีตก็กินสัญญาณอีก Deco หลังบ้านชั้น 1 อยู่ปลายสุดของสายนี้ หลักฐาน: ping ต่ำสุดเพิ่มขึ้นตามชั้น 2.8 → 4.6 → 6.3 → 7.3 ms
  • ชั้นละ 2 ตัวแย่งช่องกัน ทุกชั้นมีทั้ง Huawei และ Deco ปล่อย Wi-Fi อยู่ใกล้กัน 5GHz มีวงหนึ่งตั้งกว้าง 160MHz ทับช่อง 36–64 ทั้งหมด ส่วน 2.4GHz ใช้ช่อง 2 (40MHz), 8, 11 ทับกันหมด Huawei ยังต้องใช้ 5GHz ช่องเดียวกันนี้ส่งเน็ตลงชั้นล่างด้วย สัญญาณที่ชนกันจึงทำให้เน็ตชั้นล่างช้าลงอีกทอด หลักฐาน: ping ทุกตัวกระโดดไปถึง 63–95 ms ทั้งที่ Mac รับสัญญาณได้แรง −36 dBm
  • มือถือเกาะผิดตัว Huawei กับ Deco ไม่ได้ส่งมือถือต่อให้กันตอนเดินขึ้นลงชั้น มือถือจึงค้างกับตัวที่อยู่อีกชั้นทั้งที่สัญญาณอ่อนแล้ว

แผน: กลับไปตามความตั้งใจแรก

ความตั้งใจแรกถูกแล้ว Huawei ของ AIS 3 ตัววางหน้าบ้าน ส่งเน็ตระหว่างชั้นในแนวดิ่ง แล้วลากสาย LAN จาก Huawei แต่ละชั้นเข้าไปหลังบ้าน ให้ Deco ปล่อย Wi-Fi ตรงนั้น ชั้น 1 ทำแบบนี้อยู่แล้ว แต่ชั้น 2 และชั้น 3 ยังวาง Deco ติดกับ Huawei สัญญาณจึงออกจากจุดเดียวกันและแย่งช่องกัน ทั้งที่ควรอยู่ปลายสายหลังบ้าน

ระบบ 1 · หน้าบ้าน

Huawei AIS ×3 ส่งเน็ตระหว่างชั้น

  • วางตรงกันในแนวดิ่งอยู่แล้ว ✓
  • ปล่อย Wi-Fi ครอบคลุมครึ่งหน้าของทุกชั้น
  • เป็นต้นทางสาย LAN ที่ลากไปหา Deco
ระบบ 2 · หลังบ้าน

Deco M4R ×3 ปล่อย Wi-Fi ครึ่งหลังของตึก

  • ชั้นละ 1 ตัว วางที่ปลายสาย LAN ฝั่งหลังบ้าน
  • รับเน็ตทางสายจาก Huawei ชั้นเดียวกัน
  • อยู่ห่างจาก Huawei ตามความลึกของตึก จึงแย่งช่องกันน้อย

เน็ตทั้งบ้านยังเป็นวงเดียว (192.168.1.x) เหมือนตอนนี้ ให้ Deco อยู่โหมด Access Point ต่อไป ถ้าตั้ง Deco เป็นโหมด Router จะกลายเป็นวงใหม่ 192.168.68.x อีก แล้วกล้องกับกล่อง TV จะมองไม่เห็นกันเหมือนเมื่อก่อน

แยก Deco ให้แต่ละตัวทำงานเดี่ยว

ถ้า Deco ตัวไหนขึ้นว่าเชื่อมต่อแบบไร้สาย ทั้งที่เสียบสายกับ Huawei อยู่ ให้แยกตัวนั้นออกมาเป็นวง Deco ของตัวเอง ตัวนั้นจะส่งเน็ตหา Deco ตัวอื่นแบบไร้สายไม่ได้อีก ต้องใช้สายจาก Huawei อย่างเดียว ถอด Deco ตัวไหนก็ไม่กระทบตัวอื่น

  1. แอป Deco → กดที่ตัวนั้น (เช่น Living Room) → Remove Decoไฟจะกระพริบ เครื่องรีเซ็ตตัวเอง
  2. เช็คว่าสาย LAN จาก Huawei ชั้นเดียวกันเสียบอยู่ที่ Deco ตัวนั้น
  3. แอป Deco → เมนู ≡ → สร้างวงใหม่ (Create new network / Add a new Deco) → เลือก Deco M4R → ตั้งเป็นตัวหลัก
  4. เลือกโหมด Access Point แล้วตั้งชื่อ Wi-Fi และรหัสให้เหมือนวงเดิมทุกตัวอักษรมือถือกับกล้องจะต่อเองโดยไม่ต้องตั้งใหม่
  5. ทำซ้ำกับตัวที่เหลือ จนได้ Deco 3 วง วงละ 1 ตัว สลับดูแต่ละวงได้จากเมนู ≡ ในแอป

ลำดับลงมือ

  1. ห้ามถอด Bedroom (.101) เพราะเป็น Deco ตัวหลัก ถ้าถอดตัวนี้ Deco ตัวอื่นจะหลุดหมดถ้าจะถอดตัวหลัก ต้องแยก Deco แต่ละตัวให้ทำงานเดี่ยวก่อน (ดูหัวข้อด้านล่าง)
  2. หน้า admin Huawei 192.168.1.1: ตั้ง 2.4GHz ช่อง 1 กว้าง 20MHz, 5GHz ช่อง 36 กว้าง 80MHz, กำลังส่งสูงสุด
  3. แอป Deco: ตั้ง Wi-Fi หลักให้ชื่อและรหัสตรงกับของ Huawei และตั้ง IoT Network เป็น Joenat38_2.4G_Deco
  4. บอก Claude ให้สแกนซ้ำ เพื่อเทียบ ping กับวันนี้
  5. ลากสาย LAN (Cat6) จาก Huawei ชั้น 3 และชั้น 2 ไปหลังบ้านของแต่ละชั้น แบบเดียวกับชั้น 1
  6. เสียบ Deco ชั้น 3 และชั้น 2 ที่ปลายสาย แล้วดูในแอป Deco ว่าขึ้นการเชื่อมต่อแบบ Ethernet
  7. ย้ายกล้องหลังบ้านทุกตัวมาต่อ Joenat38_2.4G_Deco แล้วจอง IP ให้กล้องใน Huawei
